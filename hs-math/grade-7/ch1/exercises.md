# Chapter 1 Exercises

### ✏️ Exercise 1

Evaluate $(-9) + 4$.

<details>
<summary>Show Solution</summary>

The signs are different, so subtract: $9 - 4 = 5$. The larger absolute value is $9$, which is negative, so the answer is $-5$.

</details>

### ✏️ Exercise 2

Evaluate $3 - (-8)$.

<details>
<summary>Show Solution</summary>

Add the opposite: $3 - (-8) = 3 + 8 = 11$.

</details>
